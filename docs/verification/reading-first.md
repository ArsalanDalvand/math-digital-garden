# تحویل مرحلهٔ اول بازطراحی باغ ریاضی

## جهت تأییدشده
مطالعهٔ آرام و ابزارهای اختیاری؛ بدون تغییر بک‌اند یا قرارداد Markdown.

## تغییرهای اجراشده در پروژهٔ اصلی
- `docs/DESIGN.md`: توکن‌ها، تایپوگرافی، قواعد تعامل و مرزهای مرحله.
- `frontend/src/styles/custom.css`: سیستم مشترک روشن/تیره، خوانایی متن، قاب قضیه، کنترل‌های ۴۴ پیکسلی، focus و چیدمان موبایل.
- `frontend/src/pages/index.astro`: مسیر شروع نمونهٔ مطالعه، جست‌وجوی متصل به مسیر واقعی و راهنمای استفاده.
- `frontend/src/components/WorkspaceNote.astro`: ابزارهای شخصی بسته در آغاز، وضعیت ذخیره همواره بیرون بخش تاشو؛ ویرایشگر خارج از disclosure باقی می‌ماند تا بستن ابزارها متن را پنهان نکند.
- `frontend/src/components/Tutor.astro`: دستیار اختیاری با همان قرارداد API موجود.
- `tests/frontend/reading-first.test.mjs`: سه آزمون رگرسیون ساختاری؛ برای هر مسیر شکست پیش از پیاده‌سازی مشاهده و سپس موفقیت ثبت شد.

## شواهد تازه
فرمان `pnpm test && pnpm tsc && pnpm check && pnpm build` با کد خروج صفر پایان یافت.
- ۴۳ آزمون فرانت‌اند موفق؛ صفر شکست.
- TypeScript بدون خطا.
- Astro check: بررسی ۳۴ فایل؛ صفر error، warning و hint در تشخیص کد.
- build کامل شد؛ هشدارهای ساخت شامل نبود مجموعهٔ docs در Starlight، directiveهای use client وابستگی‌ها و chunkهای بزرگ است. این هشدارها حل نشده‌اند.
- خروجی واقعی build برای وجود فرم جست‌وجو، پیوند نمونه، KaTeX و برهان تاشو بررسی شد؛ هر چهار بررسی موفق.

## تحویل دیدنی
`math-garden-reading.html` پیش‌نمایش خودبسنده از خانهٔ تغییرکرده و یادداشت کانتورِ خروجی واقعی build است؛ فونت محلی و KaTeX در فایل جاسازی شده‌اند. تغییر تم و پنجرهٔ مطالعه در آن پیاده شده‌اند. جست‌وجوی پیش‌نمایش فقط روی نمونهٔ کانتور عمل می‌کند و این محدودیت در رابط نوشته شده است. این فایل جایگزین اپلیکیشن اصلی نیست.

## مرز ادعا
آزمون‌های این مرحله ساختاری/واحد و ساخت هستند، نه اثبات تجربهٔ حساب واقعی، تعامل مرورگر یا WCAG کامل. حساب، داشبورد شخصی و بازبینی هنوز بازطراحی اختصاصی نشده‌اند. مرورگر، نشست زنده، دیتابیس و پاسخ دستیار در این اجرا آزمایش نشده‌اند. عکس نیاز محتوایی این مرحله نبود؛ هیچ تصویر ساختگی یا آمار نمایشی افزوده نشده است.

## ادامهٔ اولویت‌دار
۱. جداسازی ورود و ثبت‌نام با اعتبارسنجی و خطای روشن.
۲. فضای شخصی با حالات خالی، جست‌وجو و وضعیت ذخیره/تعارض.
۳. آزمون دیداری موبایل و تم‌ها، آزمون صفحه‌کلید و کاهش بارگذاری گراف.
