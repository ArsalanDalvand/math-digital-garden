**Security Findings**
- Unsanitized HTML rendering via `set:html` in `frontend/src/components/InlinePreviews.astro:9`: `note.previewHtml` is injected directly into the template. Keyboard users tabbing sequentially through notes trigger popups unexpectedly, obscuring adjacent text and interrupting screen reader reading order.
