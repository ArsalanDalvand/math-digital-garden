منبع درخواست‌شده: `/home/a7vat4r/Documents/Obsidian/jozve/ریاضی 1/math-freamwork/`

نمونهٔ محلی: [نقشهٔ راه](http://127.0.0.1:4321/notes/math1-79bc82a780b2ee5d)، [سوپریموم و اینفیموم](http://127.0.0.1:4321/notes/math1-c2f37614f9a68928)، [فهرست همهٔ نوت‌ها](http://127.0.0.1:4321/search). مسیر نقشهٔ راه به فایل `00 MOCs/نقشه-راه.md` مربوط است؛ این فایل و `index.md` در منبع محتوای یکسان دارند.

## دادهٔ واردشده

۱۳۴ فایل Markdown و ۳ تصویر در پوشه وجود داشتند. هر ۱۳۴ نوت با همان متن UTF-8 و SHA-256 وارد `canonical_notes` شدند. import یک عملیات نمونه‌گذاری محلی بود و با `ON CONFLICT DO NOTHING` اجرا شد؛ برای تمام نوت‌های واردشده برابری بایت‌های متن، hashها، حفظ سه نوت قبلی و دست‌نخوردن فایل‌های منبع قبل از commit تراکنش assert شد. فایل‌های مخفی و symlink وارد نمی‌شوند. import دائمی یا sync خودکار جدیدی ساخته نشده است.

شناسهٔ ورودی اصلی `math1-index` است؛ بقیه slugها از prefix `math1-` و hash مسیر نسبی ساخته شدند. نام فایل به‌عنوان title حفظ شد تا wikilinkهای مبتنی بر نام فایل کار کنند. book برابر `ریاضی۱` و پوشهٔ سطح اول chapter است؛ مسیر نسبی اصلی در metadata محفوظ است. فایل Markdown در مخزن پروژه دوباره نوشته نشده و نسخهٔ نمایش در دیتابیس محلی باقی می‌ماند.

تصاویر بدون تغییر بایت در `frontend/public/vault/math-freamwork/` با همان مسیر نسبی کپی شدند. دریافت HTTP 200 و برابری بایت هر سه تصویر نیز assert شد. این کار به‌تنهایی سینتکس Obsidian embed را فعال نمی‌کند.

## محدودیت‌هایی که این نمونه آشکار کرد

- `![[image]]`، transclusion و block reference هنوز به‌صورت کامل پشتیبانی نمی‌شوند؛ در دسترس بودن تصویر از URL به معنی embed داخل نوت نیست.
- ۱۱ نام تصویر ارجاع‌شده اصلاً در پوشهٔ داده‌شده وجود ندارند: `20251227_162228.jpg`، `20251227_162551.jpg`، `20251227_163058.jpg`، `MVT.jpg`، `Rolle.jpg`، `circle.jpg`، `cosh(x).jpg`، `sinh(x).jpg`، `tanh(x).jpg`، `نمودار-نپر-لگاریتم-معکوس.jpg` و `هذلولی.jpg`. این فایل‌ها از پوشه‌های دیگر جست‌وجو یا منتشر نشده‌اند.
- HTML سفارشی نوت نقشهٔ راه با renderer امن فعلی مثل Obsidian نمایش داده نمی‌شود؛ بعضی بخش‌ها حذف می‌شوند و بخش‌های indentشده ممکن است code محسوب شوند. بنابراین ادعای حفظ ظاهر شناسنامه/اعتبارات HTML این نوت نمی‌شود؛ raw آن حفظ شده است.
- بلوک `geogebra` فعلاً کد است و نمودار تعاملی نمی‌سازد.
- KaTeX برای برخی حروف فارسی داخل `\text{...}` هشدار character metrics داد. ذخیرهٔ فرمول سالم است، ولی تایپوگرافی همهٔ این موارد به بررسی محتوایی نیاز دارد.
- audit خودکار روی نمونه یک skip در heading سطح ۳ را گزارش کرد؛ این موضوع مرتبط با ساختار Markdown/HTML نقشهٔ راه است. بلوک‌های کد اسکرول‌پذیر قابلیت focus صفحه‌کلید دارند.
- cache محدود در حافظهٔ process است؛ اولین رندر پس از restart یا تغییر محتوا همچنان هزینه دارد. نمونهٔ پایه قبل از اصلاح حدود ۳۹ ثانیه رندر و صفحهٔ اصلی حدود ۱۰٫۷ مگابایت HTML داشت. حذف KaTeX تکراری، cache و کوتاه‌شدن previewها این هزینه را کاهش داد؛ زمان و حجم نهایی در شواهد ثبت می‌شوند.

نتیجه: برای مطالعهٔ نوت‌ها، فرمول‌ها و ارتباطات، نمونه قابل استفاده است؛ پشتیبانی کامل از این vault و ظاهر تمام امکانات Obsidian هنوز تأیید نمی‌شود. هیچ تغییر منبع، migration، انتشار بیرونی یا commit Git انجام نشد.

## شواهد نهایی

۱۶ تست واحد و ۹ تست SSR پاس شدند؛ Astro check، TypeScript و build موفق بودند. پوشش ماژول‌های JavaScript مشترک ۱۰۰٪ خطوط و ۹۵٫۰۶٪ branchها است؛ پوشش DOM در این عدد حساب نشده و با agent-browser سنجیده شد.

حجم پاسخ HTML نقشهٔ راه نهایی ۶۲۵٬۱۹۳ بایت شد. روی این سیستم زیر بار، cold request نهایی ۲۷٫۳۵ ثانیه و warm request حدود ۰٫۴۰ ثانیه بود؛ یک اجرای پیشین cold حدود ۸ ثانیه و warm حدود ۰٫۰۶ ثانیه شد. تغییر به نوت دیگر با همان catalogue نیز cache را نگه داشت. زمان cold ثابت یا تضمین‌شده نیست.

در برخی navigationهای agent-browser به مسیر `math1-index` وضعیت tab به about:blank برگشت. مسیر MOC با همان Markdown و عنوان فایل فارسی در مرورگر واقعی بررسی شد و لینک نمونهٔ بالا به همین مسیر است؛ علت آن رفتار CLI تأیید نشده و ادعای رفع آن نمی‌شود.

شواهد تصویری: `verification/obsidian-vault-roadmap.png`، `verification/obsidian-vault-mobile.png` و `verification/obsidian-vault-atomic.png`. لاگ‌ها و RED/GREEN در `verification/obsidian-ui/` هستند. audit نهایی و موارد incomplete در فایل‌های `obsidian-vault-*-a11y.json` ثبت شده‌اند؛ این audit معادل تأیید دستی تمام WCAG نیست.
