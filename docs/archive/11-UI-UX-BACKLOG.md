# فهرست تحویل به متخصص UI/UX

این فهرست طبق درخواست کاربر از پیاده‌سازی عملکردی جداست. رفتارهای ضروری و دسترس‌پذیری پایه برقرار می‌مانند؛ پولیش بصری و چیدمان نهایی در این مرحله انجام نشده‌اند.

| بخش | کار طراحی/ارزیابی بعدی |
|---|---|
| مطالعه | سلسله‌مراتب محتوا، عرض ستون، فضای فرمول عریض، sidebar کتاب/فصل، قبلی/بعدی و TOC |
| رسمی/شخصی | نشانگر پایدار و واضح، تغییر حالت بدون سردرگمی، ارتباط متن و editor و graph عمومی |
| ویرایشگر | چیدمان CodeMirror و preview، تجربهٔ لمس MathLive، میانبرها، محتوای mixed BiDi |
| ذخیره | status و conflict/retry، دریافت فایل در قطعی، هماهنگی دو تب؛ هشدار خروج باید قابل فهم باشد |
| تغییر مبدأ | مقایسه با رسمی جدید، ادغام دستی بدون حذف توضیحات شخصی و تأیید آگاهانهٔ rebase |
| حساب | فرم‌ها، خطاهای ورود، خروج، نشانگر نقش و جلوگیری از ارسال دوبارهٔ فرم |
| فضای شخصی | لیست fork/bookmark، جست‌وجو و مرتب‌سازی، تاریخچه و بازیابی revision، empty states |
| پیشنهاد | دلیل اصلاح، snapshot immutable، وضعیت بررسی، resubmit، تفاوت منبع/شخصی/نسخهٔ پیشنهادی |
| بازبینی | MergeView فارسی، تعیین منابع اختلاف، focus/scroll، تصمیم‌گیری، تأیید و پیام تعارض |
| خروجی گیت | نمایش pending/failed/synced، علت conflict و راهنمای retry و pull در Obsidian |
| دستیار | محل قرارگیری، متن انتخابی و پرسش‌های سریع، انتظار، خطا، citations و اعمال صریح |
| گراف | سطح/فیلتر/تنظیمات، حالت fullscreen، مرور با کیبورد و جایگزین متنی |
| پیش‌نمایش | hover/focus/touch، مدیریت viewport، قرار دادن لینک مطالعهٔ کامل |
| GeoGebra | اندازهٔ قاب، توضیح بارگذاری خارجی، fallback در شبکهٔ قطع و keyboard navigation |
| سازگاری والت | ظاهر HTML سفارشی و codeهای indentشده، تصاویر غایب، موارد KaTeX فارسی در text |
| ممیزی | کنتراست روشن/تیره، سطح heading، screen reader، focus، header چسبان و پوشیده‌شدن بعضی دکمه‌ها در scroll |
| موبایل | ارتفاع editor، virtual keyboard، چیدمان diff و فرم‌ها، اندازهٔ اهداف لمسی |

آزمون‌های browser فعلی رفتار را می‌سنجند؛ تأیید دستی همهٔ WCAG، طراحی نهایی و performance budget برای تمام دستگاه‌ها هنوز انجام نشده است. render سرد مجموعهٔ بزرگ، bundleهای آمادهٔ graph/MathLive و صفحات Starlight فاقد collection ثابت در فهرست performance/تولید باقی‌اند.

نمایش نقاشی‌ها: اندازه و بزرگ‌نمایی Excalidraw، تطبیق تم، حالت انتظار/خطا و رفتار لمس GeoGebra برای بررسی متخصص UI/UX باقی است.
