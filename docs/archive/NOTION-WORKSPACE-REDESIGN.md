# بازطراحی فضای مطالعه — درخواست اصلاح‌شده کاربر

جهت انتخاب‌شده کاربر: Notion-inspired workspace، نه سایت مستندات. اجرای مستقیم Hermes، بدون Codex.

## قرارداد
- سربرگ سراسری کم‌ارتفاع: برند، جستجو، فضای شخصی/حساب؛ حساب در درخت فایل‌ها پنهان نیست.
- یادداشت مرکز؛ ستون ابزار در سمت چپ فیزیکی دسکتاپ؛ گراف خودکار بدون کلیک شروع و دستیار assistant-ui همیشه در دسترس. موبایل ابزارها با دسترسی ثابت و پنل، نه سه ستون فشرده.
- ویرایش و تغییر رسمی/شخصی آشکار کنار یادداشت؛ صاحب نسخه شخصی به طور پیش‌فرض همان را می‌بیند؛ نسخه رسمی با query explicit حفظ می‌شود.
- پالت خنثی Notion-inspired، خطوط ظریف، بدون hero غول‌پیکر یا قالب مستندات برای صفحات کاری؛ Vazirmatn و فرمول LTR حفظ.
- assistant-ui واقعی به عنوان React island؛ adapter به قرارداد SSE فعلی سایت، بدون bypass مجوز. وضعیت خطا/عدم پیکربندی واقعی، نه پاسخ ساختگی.
- گراف فقط metadata عمومی؛ lazy import خودکار بعد از آماده‌شدن صفحه برای جلوگیری از بلوکه‌کردن مطالعه. خطا retry دارد.

## مراحل و گیت
1. اجزای shell و tool rail، graph auto، کنترل editor آشکار.
2. React integration و assistant-ui adapter با حفظ context/hash/selection و cancellation.
3. default private بعد از پاسخ معتبر owner endpoint؛ unauthenticated همچنان canonical. پنل شخصی هنگام نیاز authentication error دارد.
4. test/check/tsc/build و agent-browser روی API واقعی 8001؛ تصاویر دسکتاپ/موبایل و حالات خطا. بارگذاری صفحه جای کیفیت بصری نیست؛ تصاویر خوانده شوند.

Notion الهام سازمان‌دهی و craft است، نه کپی دارایی یا ادعای استفاده از سورس اختصاصی آن. تغییر رفتار قبلی graph click و disclosures مطابق درخواست جدید است؛ تست‌های منسوخ باید با قرارداد جدید جایگزین شوند.
