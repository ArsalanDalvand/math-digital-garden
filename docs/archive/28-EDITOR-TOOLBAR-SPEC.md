# Markdown editor toolbar

Reference: Docmost fixed-toolbar.tsx, fixed-toolbar.module.css, inline-marks-group and lists-group inspected directly. Keep existing garden theme and raw Markdown editor; no rich-text conversion.

New EditorToolbar.astro renders grouped native, labeled controls and an accessible link dialog. New pure editor-commands.mjs generates one bounded replacement and selection for headings/paragraph/quote/code, inline marks, lists/checklist, HTTP(S) links, inline/block mathematics and a table. New editor-toolbar.ts binds CodeMirror selection/dispatch and existing undo/redo; returns a cleanup function. Root owns mounting in WorkspaceNote and visibility by editing state/fixed_toolbar preference.

Acceptance: transformations leave all bytes outside the replacement unchanged, preserve line endings in selected blocks, retain raw formula content, reject unsafe link schemes and invalid ranges, skip formatting in code syntax nodes, preserve pointer selection, return focus after commands, support keyboard toolbar navigation and narrow-screen scrolling. Unit checks run first and fail before implementation. No text color/alignment controls because current Markdown contract has no lossless representation. No new dependencies.

Verification: first node test failed because editor-commands.mjs was absent (exit 1). Final focused checks: 6 command tests pass, including all toolbar replacement boundaries, CRLF, code context, unsafe URLs, delimiter collisions and a leading empty line. Three AccountMenu execution tests (transpiled actual component effect, mocked transport) verify serialized reading/theme persistence, last changes winning, stale/unmounted identity suppression and failure status without a saved claim. No new dependency. Current CodeMirror reference fetched with Context7 library then docs (/codemirror/website); existing undo/redo use view commands and history from basicSetup.

AccountMenu emits guarded garden:identity {id,role}/null and garden:preference-save {state:saving|saved|error}. ReadingSettings emits only user-triggered garden:reading-settings; server garden:preferences updates controls without another save. Reader theme toggle emits garden:theme-setting, displays save status, and listens for system color changes only while system theme is selected. Account profile blocks stale responses and disables settings after an identity change.
