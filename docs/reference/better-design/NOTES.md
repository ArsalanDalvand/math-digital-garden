# نکات استخراج‌شده برای باغ ریاضی

## سبک Notion در منبع

`globals.css` زمینه و card سفید، متن نزدیک به سیاه، سطح ثانویهٔ گرم و کمرنگ، border ملایم، ring آبی و `--radius: 0rem` دارد. نمونهٔ button دکمهٔ اصلی تیره، حالت ghost و واکنش رنگی ۱۰۰ میلی‌ثانیه‌ای دارد؛ input زمینهٔ خاکستری بدون border، ارتفاع ۳۲ پیکسل و حلقهٔ focus دارد؛ card شعاع ۱۰ پیکسل و سایهٔ بسیار کم دارد. sidebar با border باریک و حالت انتخاب مشخص ساخته شده است. kit، Feather را برای این سیستم برمی‌گزیند. این‌ها شواهد source هستند، نه الزام به جایگزینی فونت فارسی یا کتابخانهٔ آیکون نصب‌شدهٔ پروژه.

## اصول دریافت‌شده از MCP

- `ui-spacing`: فاصله باید رابطهٔ عناصر را نشان دهد؛ کنترل کنار چیزی باشد که تغییر می‌دهد؛ عرض متن و پنل محدود بماند و لایهٔ پنهان قابل فوکوس نباشد.
- `ui-typography`: نقش‌های متنی مقیاس مشخص و طول سطر خوانا داشته باشند؛ متن فارسی و فرمول/کد جهت مناسب خود را حفظ کنند.
- `ui-color`: رنگ نقش معنایی داشته باشد؛ وضعیت فقط با رنگ بیان نشود؛ متن معمولی حداقل نسبت کنتراست WCAG برابر ۴٫۵:۱ داشته باشد.
- `ui-accessibility`: focus مرئی، ترتیب صفحه‌کلید، نام کنترل‌ها و هدف لمسی حداقل ۴۴×۴۴ پیکسل بررسی شود.
- `ux-navigation`: موقعیت کنونی، مسیر بازگشت و وضعیت navigation در URL روشن باشد؛ ناوبری موبایل در دسترس بماند.
- `ux-forms`: label و خطای قابل‌اقدام کنار فیلد باشند؛ ارسال تکراری مهار شود و متن واردشده پس از خطا باقی بماند.
- `review-rules`: ۵۷ شناسهٔ `rule/...` برای دسترسی‌پذیری، محتوا و طراحی بصری دارد. نمونه‌های مرتبط: `rule/touch-target-min-44px`، `rule/focus-needs-visible-indicator`، `rule/one-visible-page-title` و `rule/consistent-displayed-state`. متن و استثناهای دقیق در JSON اصلی‌اند.

## نسبت با کد فعلی

پروژهٔ قدیمی در `frontend/src/styles/workspace.css` بخشی از رنگ‌های Notion را با توکن‌های Starlight و فونت Vazirmatn ترکیب کرده است. در `frontend/package.json`، `@base-ui/react`، `class-variance-authority`، `lucide-react` و Tailwind موجودند؛ نمونه‌های registry گاهی Radix یا فرض‌های shadcn دیگری دارند. برای بهبود بعدی، از توکن‌ها و الگوها استفاده کنید و پیش از هر نصب، نیاز واقعی و سازگاری را بررسی کنید. متن اصلی Markdown و رفتار دسترسی باید حفظ شوند.

## روش دریافت و حد اعتبار

MCP داخل همین نشست همچنان خطای transport داشت، ولی درخواست JSON-RPC `tools/call` از طریق `proxychains4` و `curl` به endpoint رسمی با HTTP 200 پاسخ داد. پاسخ‌ها در `mcp/` ذخیره شدند؛ هیچ کلید یا header محرمانه‌ای ذخیره نشد. منبع GitHub نیز در commit بالا ثابت است. قواعد ممکن است بعداً تغییر کنند؛ پیش از تصمیم تازه، نسخهٔ زنده را دوباره بگیرید. بازبینی `check-comprehension` و `inspect-spacing` برای یک صفحهٔ مشخص و DOM رندرشده هنوز انجام نشده است.
